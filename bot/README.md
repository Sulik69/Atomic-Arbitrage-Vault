# Devnet setup

This starter is pinned to Anchor 0.32.1 and the current Devnet program IDs for
Orca Whirlpool and Raydium CPMM. The program ID in `Anchor.toml` and
`src/lib.rs` is a placeholder; replace it with the ID for your own deployment.

1. Install the Solana CLI and Anchor 0.32.1. Create a Devnet wallet for the
   vault administrator and a separate bot wallet. Keep both keypairs outside
   Git and fund them with Devnet SOL.
2. Generate the program keypair, sync the program ID, then build and deploy:

   ```sh
   mkdir -p target/deploy
   solana-keygen new --no-bip39-passphrase -o target/deploy/arbitrage_vault-keypair.json
   anchor keys sync
   anchor build
   solana config set --url https://api.devnet.solana.com
   anchor deploy --provider.cluster devnet
   ```

   Confirm `anchor keys list` matches the IDL address before proceeding.
3. Select two classic SPL-token mints (USDC and an intermediate token), an Orca
   Whirlpool containing those two mints, and a Raydium CPMM pool containing the
   same pair. They must all be on Devnet. Raydium's input vault must hold the
   intermediate token; its output vault must hold USDC.
4. Copy `.env.example` to `.env` and fill in the public mint/pool/account
   addresses. `ORCA_TICK_ARRAY_0..2` must be the ordered arrays required by the
   current Whirlpool tick and swap direction; refresh them when the price moves
   across an array boundary. `RAYDIUM_*` accounts are from the selected CPMM
   pool. The scanner checks their owners and token mints before simulating.
5. Set `ANCHOR_WALLET` to the bot keypair file and `ARB_IDL_PATH` to the IDL
   generated by `anchor build`. Initialize once using the administrator wallet
   and the bot public key:

   ```sh
   ANCHOR_WALLET=/path/to/admin.json BOT_AUTHORITY=<bot-public-key> \
     pnpm --filter @workspace/arb-bot run vault:init
   ```

   If changing the bot later, use `vault:set-bot` with `ANCHOR_WALLET` set to the
   administrator wallet and `BOT_AUTHORITY` set to the new bot public key.
6. Run the scanner:

   ```sh
   pnpm --filter @workspace/arb-bot run dev
   ```

The scanner's spot-price calculation is only a candidate filter. It is not a
swap quote. It signs and simulates the actual on-chain route, and broadcasts
only when simulation succeeds; the program independently checks the realized
USDC balance increase. AMM fees/slippage are reflected in the realized USDC
balance. The bot pays Solana transaction fees in SOL, not from the USDC vault.

This is a Devnet implementation scaffold, not audited financial software. The
raw CPI encodings and account order are deliberately pinned to the legacy Orca
`swap` and Raydium CPMM `swap_base_input` instructions. Before real funds are
used, pin and verify the deployed program binaries/IDLs, add Devnet integration
tests for the exact pools, and obtain an independent security audit. Do not
deploy this Devnet-targeted program to mainnet.
